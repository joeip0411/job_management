# Tone Examples

Same underlying achievement, rewritten for different JD tones. Use as calibration — not templates to copy verbatim.

## Achievement: improved an ETL pipeline's reliability

**Source (master resume):**
> Worked on the data ingestion pipeline. Made it more reliable by adding retries and better error handling. Reduced failed jobs by about 60%.

**Scrappy startup JD** (values: speed, ownership, ship-it):
> Owned the ingestion pipeline end-to-end; shipped retry + error-handling overhaul that cut failed jobs 60%.

**Enterprise / regulated JD** (values: rigor, methodology, reliability):
> Redesigned ingestion pipeline's failure-handling layer (retry policies, structured error taxonomy), reducing failed job rate by 60% and improving SLA compliance.

**Research / ML JD** (values: experimentation, measurement):
> Diagnosed failure modes in ingestion pipeline through systematic logging analysis; introduced targeted retry policies that reduced failure rate from X% to Y% (~60% relative improvement).

## Achievement: built a dashboard

**Source:**
> Built a dashboard in Tableau to show sales metrics to the leadership team. They used it in their weekly meetings.

**Customer-obsessed product JD:**
> Partnered with sales leadership to build a Tableau dashboard adopted as their core weekly review surface, surfacing the metrics they actually used to make calls.

**Analytics / data JD:**
> Built executive sales dashboard (Tableau) consolidating 6 source systems; adopted as primary leadership review artifact.

**Engineering-leaning JD:**
> Designed and shipped Tableau dashboard backed by SQL pipeline aggregating sales data from 6 sources; deployed for weekly executive review.

---

## The tell

The achievement is the same fact. What changes is which *aspect* you foreground — ownership, methodology, customer impact, technical depth. Pick the aspect the JD signals it cares about, and lead the bullet with it.
